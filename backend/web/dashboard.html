Role Based Workflow

按步骤完成教学资料生成

登录后系统会根据管理员、教师、学生三类角色生成不同的操作步骤。

Template Center

模板中心

先选结构，再填内容，让后续生成链路稳定而统一。

Template Maintenance

模板维护与回滚

上传全新模板，或为现有模板追加版本并按版本号快速回退。

选择一个模板后查看版本

新增模板

上传新版本

Plan Generator

教学方案生成

输入课程参数后，自动组织教学目标、环节时间、案例与课堂练习。

建议把目标写得更具体，系统匹配的内容结构和案例会更贴近实际教学场景。

Courseware Generator

教学课件生成

从成功方案继续推进，自动拼装成适合课堂展示的课件页结构。

资源引用

勾选的资源会作为案例、图片或补充内容一起参与课件结构生成。

Exam Generator

试卷生成

从已成功的教学方案自动生成考试试卷，包含单选、判断、填空、简答和论述/计算五种题型。

选择一个已生成成功的教学方案，系统将从其知识点、重点、难点、案例和公式中自动出题。

Resource Hub

教学资源

把案例、图片、视频、公式和习题维护成可复用的资源池。

标签越具体，方案与课件在后续引用时就越容易命中正确素材。

User Console

用户管理

管理员可创建用户、切换角色、启停账号，并按需重置密码。

仅管理员可使用本区域。

Task Timeline

任务中心

集中查看每个方案或课件任务的进度、结果对象和导出入口。

Manual Editing

人工编辑与再生成

选择成功任务后，可直接调整生成内容 JSON，保存后系统会重新生成预览、Word/PPT 文件并写入校验记录。

点击任务卡的“编辑”自动载入内容

Live Preview

结果预览

点击成功任务的“预览”，即可在这里查看实际生成的 HTML 成果。

选择一个成功任务后查看预览

Audit Trail

审计日志

管理员可查看登录、上传、生成、编辑、导出等关键行为，便于追踪演示流程和排查异常。
