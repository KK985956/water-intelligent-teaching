# Open Source PPT Templates

This directory contains 30 PowerPoint templates copied from the
`__tests__/pptx-templates` directory of the `singerla/pptx-automizer` project.

- Source: https://github.com/singerla/pptx-automizer
- License: MIT
- Retrieved for this project as editable seed templates for courseware export
  and template-center testing.

The MIT license text is included in `LICENSE.pptx-automizer.txt`.
